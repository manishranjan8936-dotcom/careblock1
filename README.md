🔧 Core Smart Contract Functions
The Project.sol contract includes three main core functions:

registerPatient() - Allows admin to register new patients in the system
registerHealthcareProvider() - Enables admin to register and verify healthcare providers
addMedicalRecord() - Allows verified providers to add medical records for patients
